# 飞书开发 Base 使用说明

开发 Base 已按三张表创建。真实 Base token、table ID 和 field ID 只保存在
被 Git 忽略的 `configs/feishu/dev_base_profile.local.json` 中，不写入公开文档。

## 你需要填写的内容

打开“种子题”表，只填写“题目”列即可。以下字段均可留空：

- `sft_id`：摄取器自动生成；从旧 JSONL 导入时可保留原值。
- `题型（可选）`：为空时由分类工具判断。
- `参考答案（可选）`：只作输入参考，不直接视为最终标准答案。
- `备注（可选）`、`补充附件（可选）`。

其余字段由 Agent/Harness 写入：摄取状态、文本编码状态、数据错误原因、内容哈希、最近处理日期和最近运行 ID。

## Agent 输出表

“候选结果”表保存每个 candidate revision 的质量结论、难度粗筛、一致性、标准答案、真实 Qwen Passrate、最终结论和审计 ID。模型不能直接写该表；后续由字段白名单 Outbox 写入。

“流程统计”表按批次、任务模式、题型和流程阶段保存待处理、运行中、通过、拒绝、隔离、机器剩余、合格缺口和同步失败数量。

## 615.jsonl 适配结论

- 108 条记录；
- 108 个唯一 `sft_id`；
- 0 条空题目；
- 每条 Schema 均为 `sft_id + question`；
- 问题长度为 240–1300 字符，平均约 685 字符；
- JSONL 结构有效，但题目正文存在明显乱码编码，导入前必须经过编码检查，不能静默作为正常中文题目发布。

字段定义的版本化 JSON 位于 `configs/feishu/fields/`。字段结构变更必须先在测试 Base 验证并读回，不在生产表上首次尝试。
